One keyboard and mouse for every computer on your desk.

Move the pointer past the edge of a screen to work on the computer next to it. Copy on one computer and paste on another, or drag a file across. It works between Mac, Windows and Linux computers on your local network.

Now move your pointer across a seam.

Three things follow your pointer

Keyboard and mouse

The keyboard goes with the pointer, so you type on the computer you are pointing at. Lock the pointer to one computer while you work, jump to another with a shortcut, or switch to relative mouse for games.

Clipboard

Copy on one computer and paste on another: plain and formatted text, and images. Files you copy in Finder, File Explorer or your Linux file manager paste on the other computer too. Anything your password manager marks as secret stays where it is.

Files

On a Mac or PC, drag files across the edge of the screen and drop them on the other computer. From any computer, Linux included, you can also use Send Files or drop files on a computer in the arrangement. They go straight there over your network.

A native app on each computer

InputWeave lives in the menu bar on a Mac, in the notification area on Windows and in its own window on Linux. In Settings, you place the computers as they sit on your desk; a seam marks each place where the pointer crosses.

Set up in a few minutes

  1. Install it on each computer

    Download InputWeave for each of your computers. On a Mac, it asks for Accessibility and Input Monitoring the first time it runs.

  2. Pair them

    One computer shows a 6-digit code. Type it on the other, and they trust each other from then on.

    482 913

  3. Arrange the screens

    Drag the computers to match where they sit on your desk. Where two screens meet, a seam shows where the pointer crosses.

It stays on your network

No account, no cloud

Computers find each other on your local network and connect directly. Your keystrokes, clipboard and files never pass through a server.

Encrypted between your computers

Every connection uses mutual TLS over QUIC, pinned to each computer’s own certificate. A new computer joins only with the pairing code shown on yours.

Two reasons to go online

InputWeave checks for a new version, which you can turn off, and talks to Polar only if you add a license. Nothing else leaves your network. Privacy
