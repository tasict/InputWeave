# InputWeave 1.0.1

This update fixes a rare crash of InputWeave's background service. Install it on every computer: the macOS and Windows apps offer it themselves, and on Linux it comes with your system's software updates.

## Fixed

- **The background service could crash.** A timing bug in Tokio, the library it runs on, could free a timer while it was still firing, which crashed the service or, rarely, corrupted its memory. The heartbeats between your computers and the service's regular checks used that timer. (RUSTSEC-2026-0384)
- **A cryptography helper compared values in a time that could depend on them.** It is updated to the version that does not. (RUSTSEC-2026-0385)

## Changed

- **Linux:** InputWeave talks to the desktop (its portals, the clipboard, the lock screen and the tray icon) through newer versions of the D-Bus libraries it uses. Nothing should look different; if something on your desktop behaves differently from 1.0.0, please [report it](https://inputweave.ctsite.cc/issues).

The [user guide](https://inputweave.ctsite.cc/user-guide) covers setup and everything else.
