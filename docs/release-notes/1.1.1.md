# InputWeave 1.1.1

On a Mac, other computers can now type and click on the lock screen, and at the login window if you turn it on: Apple has granted InputWeave the permission for the virtual keyboard and mouse this needs. The macOS app offers the update itself. On Windows and Linux nothing changes; this version only keeps every computer on the same version number.

## New

- **Mac: the lock screen.** While a Mac is locked, the pointer moves onto it as onto any other computer, and you can type its password and click on the lock screen from another computer. Settings › General › Lock Screen now says "Other computers can type and click on this Mac's lock screen." While another computer types there, this Mac's own mouse and keyboard don't take control back until it's unlocked; press the take-back shortcut on the controlling computer instead.
- **Mac: the login window.** Turn on "Let other computers control this Mac at the login window" in Settings › General › Lock Screen. From the next time the login window appears, for example after logging out, other computers can choose a user there and type the password. The [user guide](https://inputweave.ctsite.cc/user-guide) says what works at the login window and what doesn't.

This is new and hasn't been tested by hand as widely as the rest of InputWeave. If something doesn't work as described, please [report it](https://inputweave.ctsite.cc/issues).
