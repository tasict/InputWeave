# InputWeave 1.1.0

This update adds profiles that follow the network you're on, taking a computer offline for a while, waking sleeping computers, cursor speed for each computer, single-key shortcuts, and sending files from Finder and Dolphin. The license now goes only to the computers you apply it to. Update every computer: the macOS and Windows apps offer it themselves, and on Linux it comes with your system's software updates. Some of what's new works only between computers that all run 1.1, as noted below.

## New

- **Profiles.** In Settings › Profiles, a profile says whether this computer shares at all, which computers it connects to, and whether the clipboard and files go. InputWeave picks the profile by the network you're on, recognized by its router, or you pick one yourself. A paused profile keeps the computer off the network entirely, for example on a laptop at a café. Updating puts the network you're on in the Default profile, so nothing changes until you change something. On a Mac or a Windows PC, networks can also be recognized by their Wi-Fi name if you turn that on; the system then asks for location access, used only to read the Wi-Fi name.
- **Offline for now.** Take Offline, in a computer's inspector or its right-click menu, keeps it apart from the whole group until someone brings it back: no computer controls it or is controlled by it, and the clipboard and files don't go to or from it. Any computer can bring it back, the one taken offline too. Every computer in the group needs InputWeave 1.1 for this; one still on 1.0 doesn't know about it.
- **Wake a sleeping computer.** An offline computer that can be woken has a moon next to its name and a Wake button. You can also have pushing the pointer against the edge toward it wake it, in Settings › General. It works only when that computer allows waking from the network, usually over a wired connection; the [user guide](https://inputweave.ctsite.cc/user-guide) says how on each system.
- **Cursor speed for each computer.** A slider in each computer's inspector makes the pointer move faster or slower there, from 50% to 300%, which helps with large or high-resolution screens.
- **Single-key shortcuts.** Take back control and Lock can be one key that typing doesn't use: F13 to F19, or Scroll Lock or Pause on Windows and Linux. A new option, off by default, takes back control when you press Control twice.
- **Send files from the file manager.** On a Mac, select files in Finder and choose Services › Send with InputWeave; on Linux, Dolphin has Actions › Send with InputWeave. Windows keeps its Send to › InputWeave.

## Changed

- **The license.** It no longer passes to paired computers by itself. On a licensed computer's License page, Apply License sends it to the computers you choose, which activate it in the background, and Revoke License… takes it back and frees that computer's place at once. Removing a computer that uses the license can revoke it at the same time. Licenses already on your computers stay as they are. A computer still on InputWeave 1.0 can't have the license revoked from here until it's updated.
- **Choosing where files go.** When you send files, every computer is listed, and those that can't receive them are greyed out with the reason.

## Fixed

- **Linux:** on X11 desktops other than GNOME and Plasma, such as Xfce or MATE, the Arrangement page now shows the desktop picture.
- Changing shortcuts from two apps at once, or from the command line while an app changes them, no longer times out.

The [user guide](https://inputweave.ctsite.cc/user-guide) covers setup and everything else. If something doesn't work as described, please [report it](https://inputweave.ctsite.cc/issues).
