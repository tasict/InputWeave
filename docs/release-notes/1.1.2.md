# InputWeave 1.1.2

This update keeps the desktop pictures on the Arrangement page and the panel's map from disappearing. Update every computer: the macOS and Windows apps offer it themselves, and on Linux it comes with your system's software updates.

## Fixed

- **Desktop pictures that disappeared.** When InputWeave started on a computer, for example after signing in, updating or restarting it, the other computers lost that computer's desktop picture until it was read again. On a Windows PC that could take a few minutes after signing in, and lasted for as long as nobody was signed in. Now the other computers keep the picture they have until the computer has read its own. The fix comes with updating the computer whose picture disappeared.

If something doesn't work as described, please [report it](https://inputweave.ctsite.cc/issues).
